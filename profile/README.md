# Nexora is now NX — we moved to [github.com/nx-panel](https://github.com/nx-panel)

Every repository of this organization was transferred to **[nx-panel](https://github.com/nx-panel)** and renamed:

| Old | New |
|---|---|
| `Nexora-VPN/panel` | [`nx-panel/panel`](https://github.com/nx-panel/panel) |
| `Nexora-VPN/node` | [`nx-panel/node`](https://github.com/nx-panel/node) |
| `Nexora-VPN/shop`, `notif`, `addon-kit`, `addon-template` | [`nx-panel/…`](https://github.com/nx-panel) (same names) |
| `Nexora-VPN/nexora-migrate` | [`nx-panel/nx-migrate`](https://github.com/nx-panel/nx-migrate) |
| `Nexora-VPN/nexora-openvpn` | [`nx-panel/nx-openvpn`](https://github.com/nx-panel/nx-openvpn) |

Version **v0.1.0** is the first NX release. Upgrading from Nexora is a manual
install with the new script, which moves an existing Nexora install first —
the panel's own update button cannot do it. See the release notes of
[nx-panel/panel](https://github.com/nx-panel/panel/releases).
